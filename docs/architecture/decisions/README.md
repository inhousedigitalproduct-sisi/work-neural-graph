# Architecture Decision Records

Gunakan folder ini untuk keputusan arsitektur lintas modul yang perlu mempertahankan konteks historis.

Format file: `NNNN-short-title.md`.

Template:

```markdown
# ADR NNNN - Title

## Status
Proposed | Accepted | Superseded

## Context
Masalah dan constraint.

## Decision
Keputusan yang dipilih.

## Consequences
Trade-off, migration, testing, performance, dan operational impact.
```

Jangan gunakan ADR untuk perubahan UI kecil. `Architecture.md` tetap berisi standar aktif; ADR menjelaskan mengapa standar besar berubah.
